# متافایننس (MET)

سیستم مالی شخصی فارسی و راست‌به‌چپ: درآمد، هزینه، دارایی، خزانه طلا و دلار، کسب‌وکار، یادداشت و گزارش. داده‌ها فقط روی دستگاه شما در IndexedDB ذخیره می‌شوند و برنامه آفلاین کار می‌کند.

## ساختار پروژه

```
index.html            ← صفحهٔ آمادهٔ اجرا (جاوااسکریپت کامپایل‌شده)
assets/               ← فایل‌های کامپایل‌شدهٔ برنامه
manifest.webmanifest  ← تنظیمات نصب PWA
sw.js, precache.json  ← کش آفلاین
icon-*.png, icon.svg  ← آیکون‌ها
src/                  ← سورس برنامه (برای توسعه)
public/               ← فایل‌های عمومی سورس
vite.config.ts, tsconfig.json, package.json
```

**مهم:** `index.html` ریشه و پوشهٔ `assets/` همان خروجی آمادهٔ اجراست. آن‌ها را با فایل‌های `src/` جایگزین نکنید.

## انتشار روی GitHub Pages (بدون بیلد)

1. محتوای این بسته را در ریشهٔ مخزن آپلود کنید؛ **پوشه‌ها را با ساختارشان** (`assets/`, `src/`, `public/`)، نه فقط فایل‌های داخلشان.
2. در GitHub: `Settings → Pages`، مقدار Source را `Deploy from a branch` بگذارید؛ شاخهٔ `main` و پوشهٔ `/ (root)` را انتخاب و Save کنید. منتظر پایان موفق انتشار بمانید.
3. آدرس `https://<username>.github.io/<repo>/` را باز کنید.

مسیرها نسبی‌اند و هم در ریشه و هم در زیرمسیر کار می‌کنند.

## اجرای محلی

```bash
npm ci
npm run dev        # توسعه
npm run typecheck  # بررسی تایپ
npm test           # تست‌های محاسبات، نرخ، CRUD، ذخیره‌سازی و PWA
npm run build      # ساخت مجدد dist/ (نیازمند منابع کافی)
```

پس از `npm run build`، تمام محتوای `dist/`، شامل `index.html`، پوشهٔ `assets/`، `sw.js`، `precache.json`، manifest و آیکون‌ها را با حفظ ساختار در ریشهٔ محل انتشار کپی کنید. فایل‌های یک build را با build دیگری مخلوط نکنید؛ پوشهٔ `src/` ورودی توسعه است و نباید جایگزین صفحهٔ اجرایی ریشه شود.

## نرخ‌ها، اطلاعات اولیه و ویرایش رکوردها

- اجرای تازه بدون کسب‌وکار، دارایی، تراکنش، یادداشت یا موجودی نمایشی شروع می‌شود. فقط قالب صندوق‌ها و درصد بودجه‌بندی اولیه وجود دارد. دادهٔ معتبر قبلی کاربر خودکار پاک نمی‌شود؛ برای جداسازی داده‌های قدیمی، ابتدا پشتیبان بگیرید.
- نرخ طلا، دلار، سکه امامی و بهار آزادی از [NerkhAra](https://nerkhara.com/en/api/) دریافت می‌شود؛ منبع پشتیبان [Iran Market](https://iran-market.github.io/) است. این منابع عمومی‌اند و کلید محرمانه‌ای در کلاینت وجود ندارد.
- دریافت خودکار هنگام ورود، بازگشت به تب یا اتصال مجدد و سپس هر پنج دقیقه در تب فعال اجرا می‌شود. هر منبع هشت ثانیه مهلت دارد؛ درخواست‌ها هم‌پوشانی ندارند. دکمهٔ به‌روزرسانی و ورود دستی نیز وجود دارد.
- واحد ورودی باید تومان (IRT) و هر چهار نرخ معتبر باشد. نرخ اعلام‌شدهٔ قدیمی، بیش از ۳۰ دقیقه یا دارای زمان نامعتبر رد می‌شود؛ زمان نمایش‌داده‌شده زمان خود منبع است، نه زمان بازکردن صفحه. هنگام تعطیلی بازار ممکن است نرخ تازه‌ای پذیرفته نشود.
- در قطعی هر دو منبع، آخرین نرخ معتبر حفظ و خطا نمایش داده می‌شود؛ مقدار جعلی جایگزین نمی‌شود. دریافت تازهٔ نرخ نیازمند اینترنت و اجازهٔ CORS منبع است. دسترسی واقعی هر دو منبع از محیط توسعه در این نوبت تأیید نشد؛ fallback و schema با پاسخ‌های کنترل‌شده تست شده‌اند.
- ویرایش و حذف برای تراکنش، گردش خزانه، کسب‌وکار، دارایی، صندوق و یادداشت در دسترس است. حذف نیازمند تأیید است. حذف یا تغییر مبلغ مالی با بازگرداندن اثر قبلی انجام می‌شود؛ در صورت مصرف موجودی مرتبط، عملیات رد می‌شود.
- تاریخ و نرخ تاریخی تراکنش هنگام اصلاح حفظ می‌شود. گردش خودکار خزانه از طریق درآمد مرتبط ویرایش/حذف می‌شود. ابتدا فروش دارایی را از دفتر تراکنش‌ها یا گزارش حذف کنید تا دارایی دوباره فعال شود؛ سپس خود دارایی قابل حذف است.
- صندوق خزانه حذف نمی‌شود. سایر صندوق‌ها فقط با سهم صفر، موجودی صفر و بدون سابقهٔ مالی قابل حذف‌اند. درصدها در بودجه‌بندی و نام در ویرایش صندوق تنظیم می‌شوند.
- در رکوردهای قدیمی که پیوند حسابداری لازم ندارند، توضیحات قابل اصلاح است، اما حذف یا اصلاح مبلغ ناامن مسدود می‌شود؛ هیچ پیوند تاریخی حدس زده نمی‌شود. حذف کسب‌وکار، تاریخچهٔ تراکنش‌های آن را پاک نمی‌کند.
- تمام تغییرات در IndexedDB همین دستگاه ذخیره می‌شود؛ وضعیت ذخیره پایین سایدبار نمایش داده می‌شود. ذخیرهٔ ابری و همگام‌سازی بین دستگاه‌ها فعال نیست. برای انتقال داده از پشتیبان JSON استفاده کنید.
- طراحی شیشه‌ای، تم روشن/تاریک، فونت Vazirmatn و رابط RTL حفظ و اصلاح شده‌اند. تست بصری در مرورگر واقعی در این محیط انجام نشده است.

## اگر صفحه سفید ماند

- مطمئن شوید `assets/` آپلود شده و نام فایل‌ها تغییر نکرده است.
- ابتدا صفحه را با Ctrl+Shift+R بازخوانی کنید. اگر مشکل ادامه داشت، در DevTools → Application → Service Workers، فقط ثبت Service Worker همین سایت را Unregister کنید و دوباره بارگذاری کنید.
- گزینهٔ Clear site data و حذف IndexedDB را نزنید؛ اطلاعات مالی روی همین دستگاه نگهداری می‌شود. قبل از هر پاک‌سازی از داخل برنامه پشتیبان JSON بگیرید.
- در Console مرورگر خطای `Failed to load resource` را بررسی کنید.
